# Palabra del día
Web que permite ver y puntuar distintas palabras o expresiones interesantes explicadas en las clases de Latín y Griego del IES Veles e Vents de Torrent. Contiene un sistema de votaciones anónimo que muestra cuál ha sido la palabra más popular en cada curso y año académico.

Proyecto convertido a web con IA, pero a partir de contenido propio.
